# Chicago Crime Analysis - November 2017

## 📋 Descrição
Análise exploratória de dados de crimes em Chicago durante novembro de 2017. 
Identificação de padrões, tendências geográficas e temporais de ocorrências criminais.

## 📊 Dados
- `moved_project_sql_result_01.csv` - Dataset de crimes
- `moved_project_sql_result_04.csv` - Dados agregados 1
- `moved_project_sql_result_07.csv` - Dados agregados 2

## 🚀 Como Executar
```bash
pip install -r requirements.txt
jupyter notebook analysis.ipynb
```

## 📈 Análises Realizadas
- Distribuição temporal de crimes
- Análise geográfica de ocorrências
- Tipos de crime mais comuns
- Padrões por bairro/região

## 🛠️ Tecnologias
- Python 3.8+
- pandas, numpy, matplotlib, seaborn
